# Saiket Systems Business Analysis Internship 🚀

## 📌 Project Overview

This repository contains tasks completed during the Saiket Systems Business Analysis Internship Program. The project focuses on customer churn analysis, data cleaning, exploratory data analysis, customer segmentation, and advanced business insights using the Telco Customer Churn dataset.

### 🔹 Internship Domain

Business Analysis

### 🔹 Tools & Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab
* GitHub

### 🔹 Skills Gained

* Data Analysis
* Data Cleaning
* Exploratory Data Analysis (EDA)
* Data Visualization
* Customer Segmentation
* Statistical Analysis
* Business Insights Generation

### 🔹 Dataset Information

The dataset contains customer information related to:

* Customer demographics
* Tenure
* Monthly charges
* Contract types
* Payment methods
* Customer churn status

### 🔹 Tasks Completed

✅ **Task 01: Understand the Dataset**

* Loaded and explored the dataset
* Checked data types and missing values
* Examined dataset structure

✅ **Task 02: Data Cleaning**

* Handled missing values
* Removed duplicate records
* Standardized column names

✅ **Task 03: Exploratory Data Analysis (EDA)**

* Generated summary statistics
* Created histograms and box plots
* Analyzed churn distribution

✅ **Task 04: Customer Segmentation Visualization**

* Segmented customers based on tenure
* Created pie and donut charts
* Compared average monthly charges across segments

✅ **Task 05: Advanced Analysis**

* Analyzed churn by tenure groups
* Studied churn across demographics
* Evaluated payment methods and contract types
* Generated business insights through visualizations
